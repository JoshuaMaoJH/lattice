# ADR-002 不做运行时解释器，一律 codegen

## 背景

可视化工具通常有两条路：

1. **解释器**：编辑器内直接跑图。预览快，但产物和预览是两套实现。
2. **代码生成**：图 → 源码 → 编译。预览慢一点，但预览跑的就是产物。

## 决策

只做 codegen。编辑器的预览窗口是一个真实的 `flutter run` 子进程，跑的是刚生成的代码。

## 后果

**好的**：不存在"编辑器里能跑、导出后不一样"的双轨；生成代码可读、可 diff、可 eject（G5）；预览里看到的行为就是用户最终拿到的行为。

**代价**：反馈回路依赖 Flutter 热重载（目标 ≤ 2s，G3），比解释器慢；增量生成必须做对，否则每次改动都要全量重编。

**已做的准备**：`LatticeGenerator.write` 对内容未变的文件不写盘，因此 mtime 稳定，热重载只会看到真正变化的页面。`lattice build` 连续跑两次第二次报告 `0 changed`。
